Three-Layer Detection Architecture
Layer 1 — Broad Signal
Multi-Tool Sentiment Scoring
Three independent scorers per comment for a more robust signal. Negative sentiment is necessary but not sufficient — it filters the corpus without false-positives.
VADERTextBlobAFINN
Layer 2 — Domain-Specific
TF-IDF Depression Lexicon
LIWC categories (sadness, anxiety, hopelessness, exhaustion, numbness, suicidal) with locked-vocabulary TF-IDF weighting. Extended to bigrams for richer coverage.
LIWCTF-IDFbigrams
Layer 3 — High Precision
Self-Disclosure Detection
spaCy POS tagging identifies 1st-person pronoun + depression-vocabulary co-occurrence. Captures genuine personal disclosure ("I've been struggling…") rather than reactions.
spaCyPOS tagging1st-person
ML2 Course Techniques Applied
Clustering
HDBSCAN + GMM
Density-based & probabilistic clustering of sentence embeddings. AIC/BIC model selection for GMM component count.
Dimensionality Reduction
UMAP
384-dim sentence embeddings reduced to 2D preserving local neighborhood structure for visualization.
NLP
TF-IDF + Lexicon + POS
Three-layer text feature extraction combining lexicon matching, TF-IDF weighting, and part-of-speech tagging.
Supervised Learning
LR / NB / SVM Pipeline
sklearn Pipeline with 5-fold cross-validation and F1-macro evaluation. Handles class imbalance between signal and non-signal comments.
