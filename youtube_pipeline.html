YouTube Depression Signal Detection

Pipeline — share with team

Research questions 1. Across different YouTube content categories, how does the natural prevalence of depression-indicative language vary?
2. To what extent does video-level contextual framing shape the linguistic patterns of depression-related self-disclosure in comments?
Core design principle The analysis unit is the comment, not the video. We do not search for depression-related videos. We sample high-traffic videos across five everyday categories, then scan every comment for depression-indicative language using a three-layer NLP method. Depression relevance is determined entirely post-hoc at the comment level.
Step 0 Data collection

YouTube Data API v3 — five predefined categories, ranked by view count within each category. No depression keywords used.

Step 2 Comment-level depression signal detection

Input: raw comment text (with video_id) → Output: depression signal score per comment. Three layers of increasing specificity — sentiment alone is not enough.

Layer 1 Sentiment score — broad signal
Every comment scored positive / negative / neutral via RoBERTa. Baseline feature only — negative sentiment ≠ depression (e.g. "this video is garbage" is negative but irrelevant).
Layer 2 Depression lexicon matching — domain-specific
Match against LIWC categories (negative emotion, sadness, anxiety, health) and a depression-specific wordlist: "hopeless", "worthless", "exhausted", "numb", "empty", "can't go on". Filters for mental-health-relevant language beyond general negativity.
Layer 3 Self-disclosure detection — high precision
First-person pronoun + depression-indicative vocabulary combinations: "I feel hopeless", "I've been struggling", "I can't do this anymore". These represent genuine personal disclosure — the strongest research signal.
Embedding
all-MiniLM-L6-v2 or mental-bert. For clustering and UMAP visualization.
Clustering
HDBSCAN — noise-aware, no fixed k. Groups comments by linguistic pattern.
Output per comment
sentiment score · lexicon match rate · self-disclosure flag · cluster label · composite depression signal score

Step 4 Supervised modeling optional

Positive: high-scoring depression signal comments. Negative: low-scoring comments from general categories. Train classifiers, compare interpretable vs. deep models.

Feature vector
Sentiment + lexicon match rate + pronoun ratio + self-disclosure flag + comment embedding. Engagement-weighted by like_count.
Logistic regression
Interpretable baseline. Coefficient analysis shows which features matter most.
BERT fine-tune
Compare F1 / AUC-ROC vs. baseline. Quantifies value of deep contextual features.

Limitations to address in paper
  • Comment ≠ commenter
  • Negative sentiment ≠ depression — addressed by three-layer method
  • Top-comment bias (sorted by likes)
  • Five categories defined by research team — not exhaustive
  • No clinical ground truth
  • Frame results as: "depression-indicative linguistic signals" — not diagnosis
